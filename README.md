## 📖 About The Project

<img src="SCEO%20SEO%20Website/assets/images/desktop.png" alt="SCEO Desktop Screenshot" width="100%"/>
<img src="SCEO%20SEO%20Website/assets/images/mobile.png" alt="SCEO Mobile Screenshot" width="100%"/>

**SCEO** is a sleek and visually appealing SEO agency website built with an emphasis on **clarity**, **branding**, and **user engagement**.  
It highlights digital marketing services, client trust, and team professionalism while maintaining a balanced, modern aesthetic.  
This design serves as an ideal front-end concept for agencies offering **SEO**, **content marketing**, or **brand growth solutions**.
