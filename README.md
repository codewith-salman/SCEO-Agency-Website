## 📖 About The Project

<img src="SCEO%20SEO%20Website/assets/images/desktop.png" alt="SCEO Desktop Screenshot" width="100%"/>
<img src="SCEO%20SEO%20Website/assets/images/mobile.png" alt="SCEO Mobile Screenshot" width="100%"/>

**SCEO** is a modern and responsive SEO agency website designed to showcase digital marketing, branding, search optimization, and online growth services.

The layout focuses on:

- Professional and modern agency branding
- Clear presentation of digital marketing services
- Strong visual hierarchy and content structure
- Responsive layouts for desktop and mobile devices
- Clean typography and balanced spacing

This project demonstrates the ability to build **modern agency websites**, create professional service-focused interfaces, and deliver responsive designs with a strong emphasis on branding and usability.

Ideal for:

- SEO and digital marketing agencies
- Content marketing businesses
- Branding and growth agencies
- Freelance marketing professionals
- Front-end UI and responsive design practice
